# 前端 UI 全量优化说明

2026-11-18。基于此前 real-http-acceptance 阶段继续修改。此次只改前端展示层与对应展示测试，没有修改 Java、BFF、接口契约或 Agent 决策逻辑。

## 设计方向

米白背景、深山林绿文字/选中态、暖红色主要操作；减少同屏渐变、彩色徽章与嵌套卡片。统一页面边距、标题层级、控件高度、卡片圆角、键盘焦点和减少动效偏好。山城插画为项目内 SVG，不依赖外部图片请求。

## 样式维护

- `web/styles/tokens.css` 是唯一基础颜色/字体令牌来源；移除 `styles.css` 重复的 `:root`。
- 原 `web/styles.css` 放入 `@layer legacy`，归一化其中 305 处历史 `!important`。保留原组件和可见性规则，新 `web/styles/ui-refresh.css` 作为统一的展示层。
- 此次没有彻底删除所有遗留 CSS。后续按页面迁移时，可以删除被替代的旧规则；不要继续增加互相覆盖的 `!important`。
- 首页偏好面板不再向 DOM 注入整块 `<style>`。站点与探索卡片移除静态内联样式；真实图片 URL 等动态值保留。
- 同一目的地的重复链接已合并。新的折叠只影响展示，旅行条件仍由原业务模块处理。
- 采用 CSS cascade layers；请在支持该标准的现代浏览器调试。

## 本地调试

前端仓库根目录：

```bash
npm ci
npm run dev
npm run build
node --test $(rg --files web/src -g '*.test.mjs')
```

最后一条使用支持 shell 命令替换的终端并需要 `rg`。Windows 可在 Git Bash 中运行。

正常调试沿用原工程启动顺序：Java → BFF → Vite。开发代理仍指向原 BFF 端口。固定样例可在 Vite 中通过 `/@fs/<前端仓库绝对路径>/quality/ui-review/index.html` 打开，不需要真实账号。
